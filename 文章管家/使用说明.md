# 文章管家 · 使用说明

> 本地小工具，用来**发文**和**改元数据**。不是后台，不能上线后用（GitHub Pages 跑不了 Node）。
> 双击根目录的 `文章管家.bat` 打开，浏览器自己弹出来，**屏幕上不会留黑窗口**；
> 要停就点页面右上角的「退出」。
>
> **2026-11-02 起，双击它会顺带把博客预览也拉起来**：另开一个最小化窗口跑 `npm run dev`
> （地址 `http://localhost:4321/`）。那个窗口还在，属于博客预览自己的；管家已经不占窗口了。
> 已经在跑的不会重复启动（先查 4321 端口）。
>
> **2026-11-06 起窗口默认藏起来了。** 想看启动日志/报错的话用
> `cmd /c 文章管家.bat --run` 手动跑一次，黑窗口就会留在那儿。

## 一、界面长什么样

打开就是三列横向排开，左边和中间永远都在：

```
┌────────┬──────────┬───────────────────────────┐
│ 文章    │          │                           │
│ 入库    │ 标签/分类 │   全部文章的格子墙          │
│ 标签    │  （第二列）│                           │
│ 分类    │          │                           │
└────────┴──────────┴───────────────────────────┘
```

| 左边点谁 | 会发生什么 |
|---|---|
| **文章** | 收起第二列，回到只有文章墙的样子 |
| **入库** | 在中间**弹出一个悬浮窗**，拖 `.md` 进去，一次可以拖多篇（不影响下面的文章墙） |
| **标签** | 左边弹出第二列，列出所有标签和各自的篇数 |
| **分类** | 同上，换成分类的清单 |
| **回收箱** | 第二列列出删除过的文章，可以恢复，也可以彻底删掉 |

**中间永远显示全部文章**，点任何导航都不会把它换走。点文章标题会弹出编辑窗。

**第二列可以拖宽。** 左边栏右边缘、第二列右边缘各有一条看不见的拖动带（鼠标放上去会显出一条绿线），
按住拖就能调宽度，**下次打开还是你调过的宽度**。双击那条带子恢复默认。

第二列没单独调过时，宽度自动等于左侧栏 —— 所以两列看起来一样宽。中间的文章墙因为 `auto-fill`，
会在第二列出现、变宽变窄时**自己改变列数**，不用你管。

**右上角那颗月亮 / 太阳按钮**是白天黑夜切换。点一下换一次，选择记在浏览器里，下次打开还是你选的；
从没点过的时候跟系统走（系统深色它就深色）。

## 二、拖拽：最快的打标签方式

第二列顶部有个**搜索框**，打几个字即时过滤（只要名字里含这几个字就留下，不管位置）。
过滤完再拖，落点不会错；下面那行提示会变成「匹配 3 / 12 个标签」，让你知道筛掉了多少。
在搜索框里按 `Esc` 是**先清掉搜索词**，再按一次才收起整列。
切换「标签」和「分类」时搜索词会自动清空。

第二列打开之后，两个方向都能拖：

| 拖什么 | 拖到哪 | 结果 |
|---|---|---|
| 第二列的标签 / 分类 | 某篇文章卡片上 | 给这篇加上这个标签 / 分类 |
| 文章卡片 | 第二列具体的某一项上 | 同样，给这篇加上那一项 |

拖动过程中**落点会变成淡绿色**，松手即生效。已经有这一项的话会提示「已经有了」，不会重复加。

> 只做「加」，没做「拖出去删除」—— 删除是不可逆动作，不适合用拖的。
> 要去掉某个标签，点开那篇的编辑窗改。

**点一下第二列的某一项**（不用拖）：中间所有文章里，带这一项的正常显示、其余的淡下去，
但**不隐藏也不重排**，还是全部文章。再点一下取消。这个用来快速确认「哪些文章用了这个标签」。

## 三、入库：从 Obsidian 到站点

1. 双击 `文章管家.bat`
2. 点左边「入库」→ 中间弹出悬浮窗
3. 把 `.md` 拖进虚线框 —— **可以一次拖多篇**（或者点一下，在选文件窗口里多选）
4. 左边的**队列**会一排排出现，每篇前面一个状态点：

   | 状态点 | 意思 |
   |---|---|
   | 黄点闪一下 | 正在分析 |
   | 绿点 + 文件名 | 分析完了，等着写 |
   | 绿点 + `已写入 /posts/xxx/` | 写进去了 |
   | 红点 + 原因 | 这篇有问题，看副行那句话 |

5. **点队列里的某一篇**，右边就换成它的诊断和表单：改标题、摘要、日期、分类、标签。
   改完点另一篇接着改，**前面改的不会丢**（切走时会自动把当前表单存回那一行）。
6. 底部点「写入全部（N 篇）」一次写完；只想写当前选中这篇，点「只写这一篇」。

**写入是一篇一篇来的**：某篇摘要空着、文件名不合法，只有它会被退回来（左边标红），
其余照写，不会因为一篇不对就整批白干。有失败的会留在界面上并自动跳到第一篇没成功的；
全都写成功时弹窗自己关掉。

「清空」把队列清掉，**已经写进站点的文章不受影响**。
导入一篇的时候队列里就一行，流程和以前一样。

> 关闭弹窗时如果还有没写的篇目，会问你一句 —— 拖进来的原文只在内存里，一关就没了。
> 已经全写完的时候不会拦你。

### 自动的部分（不用你填）

| 项目 | 怎么来的 |
|---|---|
| **文件名**（= URL） | 按文章名自动翻成英文短横线式，走**本机的翻译模型**（不联网、不上传，见下面「关于翻译模型」）：`第5章 设计概念` → `5-design-concepts`、`第十二章 网络安全` → `12-cybersecurity`。**重名自动加序号**：`two-sum` → `two-sum-2`，同一批里两篇撞名也一样，按队列顺序变成 `-2`、`-3`。模型翻得不靠谱时（比如只吐出个 `Chapter 6`）退回词表，词表也命不中就退回 `post-<今天>` |
| **标题** | 直接取文件名（去掉 `.md`）。frontmatter 里另有标题的话，右边有个按钮可以换回去 |
| **摘要** | 原文件没写就自动截取正文第一段。不满意直接在框里改 |
| **日期** | 一律填今天（拖进来的那一刻），原文件里写的 `date` / `pubDate` 不沿用 —— 那是写笔记那天，不是发到站点那天。要发成别的日子，直接在发布日期栏里改 |
| **分类 / 标签** | 原文件有就带过来，**没有也不拦** |

**文件名规则**：只能英文小写、数字、短横线。因为文件名就是 URL，
中文会变成 `%E5%93%88%E5%B8%8C` 这种编码，分享出去很难看。

### 关于翻译模型

| 问题 | 情况 |
|---|---|
| 用的什么 | Opus-MT 中译英（Helsinki-NLP 出的开源模型，7800 万参数），专门做中英互译，不是通用聊天模型 |
| 装在哪 | `文章管家/models/`，290 MB。**已经在本地了**，不用再下 |
| 联网吗 | 不联网。第一次翻名字时如果 models 里没有，会自动去镜像站下一次，之后纯离线 |
| 占多少内存 | 加载后约 900 MB，**但只有翻名字那两三秒占着**。翻完子进程直接退出，内存全还给系统 —— 管家平时一点不占 |
| 有多快 | 一批六个标题约 2.4 秒（含加载 1.3 秒）；翻过的标题存在 `slug-cache.json` 里，再遇到只要 1 毫秒 |
| 准不准 | 技术术语大部分能对（`设计概念` → design concepts、`体系结构设计` → system architecture）；但词序和少数词会偏，比如 `数据库事务隔离级别` → `level-segregation-database-services`。**文件名都可以在弹窗里手改**，不满意直接改 |

### 分类和标签怎么填

两个框都是「输入 + 下拉」：

- 点进去会列出**已有的**分类 / 标签，带各自的篇数
- 打几个字就过滤，已有的匹配项排在上面
- **输入的东西不存在时，下拉最后一行会写「＋ 新建分类「xxx」」**，回车就建
- 已经建过但磁盘上还没有的项，会显示成虚线框 —— 保存后才真的建出来
- 按 `×` 去掉，输入框空着时按退格也能删掉上一个
- 中英文逗号、顿号都能分隔，粘贴一串进去也行

分类**可以一个都不留**：不归类的文章照样发，只是不出现在任何分类页。

### 系列和序号怎么填

同一个系列的几篇会**排在一起**，组内按序号从小到大。软件工程笔记就是典型：
第1章填 1、2-1章填 2、2-2章填 3、第3章填 4，这样列表里永远是章的顺序，
而不是按发布日期——那四篇的日期恰好是同一天，按日期排根本排不出来。

| 系列 | 序号 | 结果 |
|---|---|---|
| 填了 | 填了 | 同一系列聚成一组，组内按序号升序（推荐） |
| 填了 | 空着 | 也能成组，组内退回按日期排 |
| 空着 | 填了 | 序号被忽略——没有归属就谈不上组内次序 |
| 空着 | 空着 | 普通文章，和以前完全一样 |

系列名会显示在列表卡片上（「软件工程 · 2/4」），文章页底部会出现系列导航：
上一篇 / 下一篇 / 可折叠的章节目录。

**写入之后，这条稿子的「正本」就变成站点里那一份了。** Obsidian 里的原件留着当底稿，
但以后要改请改站点这份 —— 否则两边会分叉。

## 四、删除：两级，都留后路

卡片右下角有「删除」。**第一次删只是移进回收箱**：

| 在哪删 | 文件去哪 | 博客上 |
|---|---|---|
| 卡片上的「删除」 | `文章管家/回收箱/` | **立刻打不开**，也搜不到 |
| 回收箱里再点「彻底删除」 | 电脑的**回收站**（Windows 那个） | 同上，且这里再也恢复不了 |

回收箱的文件不在站点目录里，所以 Astro 构建时根本扫不到它 —— 不用做什么额外排除。
想反悔就点「恢复」；站里恰好已经有同名文章时，恢复过来的会自动改成 `xxx-2.md`，不覆盖任何东西。

## 五、编辑：改的是什么

点文章标题（或卡片上的「编辑」）弹出编辑窗，左边是元数据表单，右边是正文。

三条规矩（也是这个工具存在的理由）：

| 规矩 | 你会看到什么 |
|---|---|
| **只改你动过的那几行** | 改一个标签保存后，`git diff` 里就只有 `tags:` 那一行变。注释、空行、字段顺序、引号风格，全都不碰 |
| **正文不做任何格式化** | 不 trim、不补末尾换行、不转全角半角。改一个错字，diff 就只有那一行 |
| **绝不静默覆盖** | 保存前会重新读磁盘。文件在别处被改过（比如你又用 Obsidian 动了一下），会弹框问你要覆盖还是放弃 |

`Ctrl+S` 保存，`Esc` 关窗。有未保存改动时，关窗会拦你一下。

编辑窗顶部「在站点打开」会跳到 `localhost:4321` 对应的文章页；站点没开着就提示你先双击 `预览.bat`。

## 六、没做的功能（别找了）

| 想做的事 | 现在怎么做 |
|---|---|
| 改文件名（= 换 URL） | 手动改文件名 + 往 `site/src/data/redirects.json` 加一条跳转（ADR-011） |
| 看哪个分类有几篇 | 点左侧栏的「标签」/「分类」，第二列每项后面就是篇数 |
| 看有没有坏链、错字段 | 目前没有全站体检；单篇的问题在入库诊断里能看到 |
| 提交 git | 手动 `git add` / `git commit`（这个工具不碰 git） |

这些都在设计文档里排了优先级，真觉得缺再加 —— 加功能是加页面，不用重写。

## 七、文件在哪

| 东西 | 位置 |
|---|---|
| 工具本体 | `文章管家/`（`src/` 是后端，`public/` 是界面） |
| 启动 | 根目录 `文章管家.bat`（双击它；真正的无窗口启动是同目录 `launch-hidden.vbs`） |
| 停止 | 页面右上角「退出」；博客预览那个最小化窗口要另外关 |
| 它写的地方 | `site/src/content/posts/*.md`（文章）、`文章管家/回收箱/*.md`（删除暂存） |
| 翻译模型 | `文章管家/models/`（290 MB，不进 git，也不会被误删进回收站） |
| 翻译缓存 | `文章管家/slug-cache.json`（翻过的标题记在这，删掉只是下次重新翻一遍） |
| 端口 | `127.0.0.1:5678`（只本机可访问，没有登录） |

站点其它文件（样式、组件、配置）它一律不碰。

## 八、出问题怎么办

| 现象 | 原因 / 处理 |
|---|---|
| 浏览器显示「无法访问」 | 管家没在跑（点过「退出」，或者电脑重启过）。重新双击 `文章管家.bat` |
| 双击后什么都没发生 | 用 `cmd /c 文章管家.bat --run` 跑一次，黑窗口里会留下原话；多半是 Node 没装或 `launch-hidden.vbs` 被拦 |
| 端口 5678 已经被占着 | 已经开着一个了 —— 双击会自动把那个页面调出来，不用管 |
| 顶部「站点未运行」 | 博客预览没开。双击根目录 `预览.bat` |
| 保存时弹「磁盘上的文件更新了」 | 你在 Obsidian 或别处又改了这篇。选「取消」然后点「重新从磁盘读」 |
| 入库提示「已经有一篇叫 xxx.md 的文章」 | 正常情况下不会出现 —— 重名会自动加 `-2`。真出现了说明文件名手改成非法格式了，按提示改 |
| 彻底删除提示「交给系统回收站失败」 | 文件还留在回收箱里，没被删掉。关了管家重新打开再试一次；还不行就自己去 `文章管家/回收箱/` 手动删 |
| 左侧栏或第二列宽度看着不对 | 鼠标放到那两条分隔带上会显出一条绿线，双击它恢复默认宽度 |
| 拖拽没反应 | 要按住卡片**空白处**拖（按在标题或按钮上可能不触发）；另外第二列得先打开 |
| 文件名全是 `post-2026-11-06` | 翻译模型没跑起来。用 `cmd /c 文章管家.bat --run` 启动，看输出里有没有 `[translate] 本地翻译不可用`；`文章管家/models/` 空了会自动重下（290 MB，要等一下） |

## 九、技术上的几个取舍（免得以后好奇）

**为什么不用现成的 Keystatic / Decap CMS？**
它们要么需要 GitHub OAuth（要服务器、要登录），要么用 Markdoc 存正文 —— 后者会重写你的
`==高亮==` 和 `cpp+tab` 代码块，而我们对正文的要求是「一个字节都不动」。
详见 `搭建设计和过程/设计方案/后台工具调研.md`。

**为什么只装了一个包？**
这个仓库装 npm 包踩过 23 分钟无输出的坑（BUG-002），所以管家的服务端、界面、
入库逻辑全部用 Node 内置模块加原生 HTML/CSS/JS 写，一行框架代码都没有。

唯一的例外是文件名翻译（2026-11-06 加）：这活儿得用神经网络，没法手写。
装的是 `@huggingface/transformers`（在本机跑 ONNX 模型的运行时），
模型权重放在 `models/` 里、不进 git 也不进版本库。
代价是 `node_modules` 多了 238 MB；换来的是任意中文标题都能翻 ——
之前靠一张手工维护的词表，没收录的词翻不出来，整章课程笔记入库时六篇全叫
`post-2026-11-06`。

**为什么翻译要单独起一个进程？**
模型加载后占约 900 MB 内存，可实际用到它的只有入库那两三秒。
放在管家主进程里常驻，等于为了偶尔翻个名字一直占着 900 MB。
改成每次起一个子进程、翻完就退，管家平时是干净的，峰值也只在那几秒。
实测加载 1.3 秒，一批六个标题总共 2.4 秒，值这个开销。
