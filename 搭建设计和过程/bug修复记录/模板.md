# YYYY-MM-DD bug 修复记录

> **用法**：复制本文件为 `YYYY-MM-DD.md`（**发现日期**）再往里填。**一天一个文件**。
>
> - 一个 bug 一张卡片，编号 `BUG-001` 起**全局递增** —— 不按天重置，所以同一天文件里的编号可能不连续，也可能只有一条
> - **根因** = 这次为什么错；**反思** = 下次怎么不错。两者必须分开写，混在一起等于没写
> - 单条反思留在本卡片里；只有「多个 bug 反复踩同一个坑」才提升成通用规律，写进 `经验教训.md`
> - 卡片写最新发现的放最上面
>
> 索引见同目录 `README.md`（新建文件后记得去补两处：索引 + bug 一览）。

## 卡片格式

```text
## BUG-XXX 一句话描述问题

- 发现时间：
- 现象：看到什么样
- 复现步骤：1.  2.  3.
- 报错信息：（贴控制台 / 终端原文）
- 定位过程：怎么一步步找到原因的
- 根因：这次为什么错
- 修复：改成了什么
- 涉及文件：
- 验证：怎么确认修好了
- 反思：下次怎么不错
- 状态：待修复 / 已修复 / 待观察
```
