## 这里的规矩

| 规则 | 说明 |
|---|---|
| **一天一个文件** | 文件名是**发现日期**，`YYYY-MM-DD.md`（不是修复日期） |
| **一个 bug 一张卡片** | 卡片内按倒序排列，最新的 bug 放最上面 |
| **编号全局递增** | `BUG-001` 起，不按天重置 |
| **根因与反思分开写** | **根因** = 这次为什么错；**反思** = 下次怎么不错。两者必须分开 |
| **新建方式** | 复制同目录 `模板.md`，重命名为发现日期 |
| **通用规律另立** | 只有「多个 bug 反复踩同一个坑」才提升到 `经验教训.md`，单条反思留在卡片里 |

完整字段说明见同目录 [`模板.md`](模板.md)。
