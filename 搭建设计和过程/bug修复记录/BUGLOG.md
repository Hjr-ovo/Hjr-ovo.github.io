# bug 修复记录

> 一个 bug 一张卡片，编号 `BUG-001` 起递增。
> **根因** = 这次为什么错；**反思** = 下次怎么不错。两者必须分开写。

## 卡片模板

```text
## BUG-XXX 一句话描述问题

- 发现时间：
- 现象：看到什么样
- 复现步骤：1.  2.  3.
- 报错信息：（贴控制台 / 终端原文）
- 定位过程：怎么一步步找到原因的
- 根因：这次为什么错
- 修复：改成了什么
- 涉及文件：
- 验证：怎么确认修好了
- 反思：下次怎么不错
- 状态：待修复 / 已修复 / 待观察
```
