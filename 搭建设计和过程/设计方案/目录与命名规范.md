## 文档文件夹（已确定）

| 文件夹 | 规则 |
|---|---|
| 文件改动记录 | **一天一个文件**，文件名 `YYYY-MM-DD.md`（当天日期）；另有一份 `模板.md` |
| bug修复记录 | **一天一个文件**，文件名 `YYYY-MM-DD.md`（**发现日期**）；另有 `模板.md` 与 `经验教训.md`（跨 bug 提炼，不按日期拆） |
| 设计方案 | 中文名 `.md`，一个主题一个文件 |

> 一天一个文件的规定于 2026-09-19 改定（原为单文件累积 `CHANGELOG.md` / `BUGLOG.md`），依据见 `设计决策记录.md` 的 ADR-005。
> 代价：文件数随时间线性增长（一年约 365 个）。当前量小，若日后浏览不便，再考虑按月份归档一层。

## 文档内引用（已确定）

| 规则 | 说明 |
|---|---|
| 用**相对路径** | 相对于当前文件。从 `README.md` 引用 → `文件改动记录/2026-09-19.md` |
| 用**正斜杠 `/`** | 反斜杠在 Markdown 里是转义符，写成 `文件改动记录\2026-09-19.md` 点不动 |
| **不用**绝对路径 | 换电脑或换盘符就断 |
| **不用** Obsidian 双链 `[[...]]` | 本项目不在 Obsidian vault 内，`[[...]]` 在 GitHub / 普通编辑器里只是一串死文本 |

示例：`[查看](文件改动记录/2026-09-19.md)`
