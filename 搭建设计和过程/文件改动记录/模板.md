# YYYY-MM-DD 文件改动记录

> **用法**：复制本文件为 `YYYY-MM-DD.md`（当天日期）再往里填。**一天一个文件**。
>
> - **倒序排列**，最新改动放最上面；**一次操作 = 一行**（哪怕动了 3 个文件，也合成一行）
> - 类型只用 5 个词：新增 / 修改 / 删除 / 重构 / 样式
> - 「提交」列 = 本次改动所在的 git 提交号。提交号要提交完才知道，所以规则是
>   **写新条目时顺手回填上一条**，最新那条先标 `——`，收工前补全
> - 想查某次改动具体动了哪些行：`git show <提交号>`
> - **纯记账性提交不单独占一行**（如回填提交号、改错别字），否则会无限套娃
>
> 索引见上级 `README.md`。
