# YYYY-MM-DD 文件改动记录

> **用法**：复制本文件为 `YYYY-MM-DD.md`（当天日期）再往里填。**一天一个文件**。
>
> - **倒序排列**，最新改动放最上面
> - **一次操作 = 一张卡片**（哪怕动了 5 个文件，也合成一张）
> - 类型只用 5 个词：新增 / 修改 / 删除 / 重构 / 样式
> - **不再记录提交号**（2026-09-20 取消）。想查某次改动对应哪个提交，用
>   `git log --oneline` 按时间找，或 `git log -S "关键词"`。原因见
>   `设计方案/设计决策记录.md` 的 ADR-012
> - **改动记录只写「意图」，提交信息只写「一句话」** —— 两者分工不同：
>   想了解为什么改看这里，想了解动了哪些行看 git
>
> 索引见同目录 `README.md`（新建文件后记得去补一行）。

---

## 卡片格式

```markdown
## HH:MM 类型 · 一句话概括

**改了什么**：具体动了哪些文件、改了什么内容

**为什么**：当时的判断依据 / 要解决什么问题

**提交**：本次改动已提交
```

> 字段不用全写满：**「为什么」如果一句话说不清就多写，说得清就一句带过**。
> 别为了填字段硬凑。
