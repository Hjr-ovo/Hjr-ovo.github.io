# YYYY-MM-DD 文件改动记录

> **用法**：复制本文件为 `YYYY-MM-DD.md`（当天日期）再往里填。**一天一个文件**。
>
> - **倒序排列**，最新改动放最上面
> - **一次操作 = 一张卡片**（哪怕动了 5 个文件，也合成一张）
> - 类型只用 5 个词：新增 / 修改 / 删除 / 重构 / 样式
> - 「提交」填本次改动所在的 git 提交号。提交号要提交完才知道，所以规则是
>   **写新卡片时顺手回填上一张**，最新那张先标 `——`，收工前补全
> - 想查某次改动具体动了哪些行：`git show <提交号>`
> - **纯记账性提交不单独占一张卡片**（如回填提交号、改错别字），否则无限套娃
>
> 索引见同目录 `README.md`（新建文件后记得去补一行）。

---

## 卡片格式

```markdown
## HH:MM 类型 · 一句话概括

**改了什么**：具体动了哪些文件、改了什么内容

**为什么**：当时的判断依据 / 要解决什么问题

**提交**：`——`
```

> 字段不用全写满：**「为什么」如果一句话说不清就多写，说得清就一句带过**。
> 别为了填字段硬凑。
