## 13:58 新增 · 文章管家加白天/黑夜切换，标签分类抽屉加搜索框

用户要求两件事：给工具做一个白天黑夜的切换按钮；标签/分类弹出的那一列里也要能搜索。

**白天/黑夜切换**（只动了 `public/`）：

- 之前深色是 `@media (prefers-color-scheme: dark)` 写死的 —— 只有系统变深才跟着变，用户**没法自己选**。
  改成和站点同一套做法：`:root` 声明 `color-scheme: light`，`[data-theme='dark']` 覆盖变量并声明
  `color-scheme: dark`，由 `<html data-theme>` 决定当前主题。
- 首屏防白闪：`index.html` head 里放一段内联脚本，在样式表之前就把 `data-theme` 定好。
  判定顺序和站点一致：**手动选过听手动，没选过跟系统**，存在 `localStorage['mgr.theme']`。
- 按钮在右上角（文章数那排的最右），圆形图标：浅色下显示月亮（点它进黑夜）、深色下显示太阳。
  **两个 SVG 都渲染出来，只靠 CSS 换显示** —— 切换时不动 DOM，图标不会闪。
- 用户从没手动选过时，监听 `prefers-color-scheme` 变化跟着系统走；一旦点过按钮就以他的选择为准
  （这条在测试里验过：存了 `light` 而系统是深色，打开仍然是浅色）。
- 顺手补了 `color-scheme` 的坑：只靠 head 里的 `<meta name="color-scheme">` 会让原生控件
  （滚动条、input）跟**系统**配色走，深色系统 + 手动切白天时滚动条仍是深的。现在两边都写死。
  滚动条颜色也走变量（`--scroll-thumb`），用 `scrollbar-width: thin` + `scrollbar-color`，
  这里没写 `::-webkit-scrollbar` 那套，所以可以直接用。

**抽屉搜索**：

- 第二列顶部加 `<input type="search" id="drawerSearch">`，`input` 事件即时过滤（子串、忽略大小写）。
- 提示行会随状态变化：没搜时讲怎么拖；搜了以后变成「匹配 2 / 3 个标签」，让人知道筛掉了多少。
- 零命中时给独立空态「没有匹配「zzz」的标签」，而不是和「还没有标签」混用一句话。
- 切换「标签 ⇄ 分类」时自动清空搜索词（留着上一个关键词只会让人困惑），placeholder 跟着改。
- 打开抽屉时焦点直接落到搜索框。
- 搜索框里按 `Esc`：有词就先清词（`stopPropagation`，别让全局 Esc 把整列一起收了），没词才收列。
- `.drawer-list` 补了 `flex: 1; min-height: 0` —— 搜索框吃掉一块高度后，列表得自己吃掉剩余空间
  才滚得动；少了 `min-height: 0`，flex 子项默认的 `min-height: auto` 会把抽屉顶破。

**验证**：临时页面在 iframe 里跑端到端（跑完已删）——

- 筛「算法」得 2 条（哈希算法 / 算法基础）、「哈希」得 2 条、「zzz」得 0 条并显示空态、清空回 3 条
- 点按钮：`light → dark`，`localStorage['mgr.theme'] = dark`，title 变「切换到白天」；再点回 `light`
- 存 `light` + 系统深色 → 打开仍是 `light`（手动选择优先于系统）
- 切到分类：搜索值清空、placeholder 变「搜索分类」、条目变 1 条
- 白天/黑夜两版截图各一张，搜索框、图标、文字都正常

**为什么**：深色是跟着系统走的，工具在白天看着发白的时候没法自己调；抽屉里的标签一多
（现在只有 3 个，以后几十个）就得靠搜，靠肉眼在一列里找太慢。
