## 14:16 修改 · 站点改名、文章日期调淡、关于页精简

三件事一起做，都改的是站点（`site/`），不涉及文章管家。

**① 文章日期调淡调小**（首页卡片 + 文章详情页顶部，两个地方共用一条规则）：

- 根因不是「颜色没配」，而是 **`.post-meta` 这条规则压根不存在**。模板里 `<p class="post-meta">`
  一直按浏览器默认 `<p>` 渲染：16px、正文色 `--ink` —— 和正文一样重，在卡片里比摘要还显眼。
- 新增设计令牌 `--faint`（白天 `#a3a19a` / 深色 `#6e6c65`），比 `--muted` 再淡一档。
- `.post-meta`：`font-size: .82rem`、`color: var(--faint)`、`letter-spacing: .01em`、
  `font-variant-numeric: tabular-nums`（日期列纵向扫视不跳），间距改成 `.5rem 0 .65rem`。
- 顺带影响：分类页 / 标签页的「N 篇文章」和条目日期也带这个类，一起变淡变细 —— 同一层级的信息，
  统一更合理。归档页用的是 `.archive-date`、相关文章用的是 `.related-meta`，两者本来就是 muted 小字，
  **没动**（归档页日期是导航锚点，压太淡会难扫）。

**② 站点名**：`consts.ts` 的 `SITE.title` `Hjr-ovo 的技术笔记` → **`Hjr-ovo的博客`**。
名字只在 consts 里出现一处，改完全站生效（页头、浏览器标题、各页 `<title>` 都跟着变）。
注意新名字中间没有空格 —— 中文和「的」连写，不要照旧习惯补空格。

**③ 关于页**：

- 一句话定位改成「一名在读大学生，记录自己的学习过程。」
- 删掉「我在写什么」「最近在折腾」「常用」三节（含 `ABOUT.intro` / `doing` / `tools` 三个字段）。
- 文章数 / 分类数 / 标签数**保留**，从原来的「我在写什么」里提出来，单独放在头像下方 ——
  那三节删了之后它不能跟着消失。
- 「关于本站」从 4 段压到 2 句：静态博客怎么运作 + 没有评论/统计/广告/第三方脚本。
  原来那几段是照着对话里的话写的，留着有股「介绍自己」的腔调，删掉更干净。

**验证**：`npm run build` exit=0；产物里 `posts`/`categories`/`tags`/`search`/`about` 五个页面的
`<title>` 都是新名字；`about/index.html` 只剩「关于本站」「联系」两个 h2，三张统计卡片还在，

## 14:05 样式 · 文章管家卡片上的日期调淡调小

用户要求：文章卡片里显示的日期，字体颜色淡一点、字号小一点。

- `app.js` 的 `cardHtml()` 里，日期那格从裸 `<span>` 改成 `<span class="card-date">`，
  后面的字数顺手加了 `card-count` 类（方便以后单独调，这次没改它的样式）。
- `style.css` 新增设计令牌 `--faint`：白天 `#a3a19a`、深色 `#6e6c65`，定位是「有就行、
  不该抢眼」的附属信息，比 `--muted` 再淡一档。仍然只覆盖变量，不破坏「深色不改规则」的约定。
- `.card-date`：`font-size: 10.5px`（同一行其余是 11px）、`color: var(--faint)`、
  `letter-spacing: 0.01em`、`font-variant-numeric: tabular-nums`（同排卡片的日期等宽，扫视时不跳）。

**验证**：造 3 篇临时文章（看完已删）截 2 倍图，逐像素采样文字颜色确认规则真的生效——
白天日期 `(163,161,154)` = `--faint`、字数为 `(107,106,101)` = `--muted`；深色下 `(110,108,101)`
对 `(156,154,146)`，即深色下也确实是日期更暗。日期仍清晰可读，没有糊成一团。

**为什么**：一行里日期、字数、分类、标签平铺，日期字面最长却最没有信息量（排序默认就按日期），
抢的注意力不该和标题、分类一样多。

## 13:58 新增 · 文章管家加白天/黑夜切换，标签分类抽屉加搜索框

用户要求两件事：给工具做一个白天黑夜的切换按钮；标签/分类弹出的那一列里也要能搜索。

**白天/黑夜切换**（只动了 `public/`）：

- 之前深色是 `@media (prefers-color-scheme: dark)` 写死的 —— 只有系统变深才跟着变，用户**没法自己选**。
  改成和站点同一套做法：`:root` 声明 `color-scheme: light`，`[data-theme='dark']` 覆盖变量并声明
  `color-scheme: dark`，由 `<html data-theme>` 决定当前主题。
- 首屏防白闪：`index.html` head 里放一段内联脚本，在样式表之前就把 `data-theme` 定好。
  判定顺序和站点一致：**手动选过听手动，没选过跟系统**，存在 `localStorage['mgr.theme']`。
- 按钮在右上角（文章数那排的最右），圆形图标：浅色下显示月亮（点它进黑夜）、深色下显示太阳。
  **两个 SVG 都渲染出来，只靠 CSS 换显示** —— 切换时不动 DOM，图标不会闪。
- 用户从没手动选过时，监听 `prefers-color-scheme` 变化跟着系统走；一旦点过按钮就以他的选择为准
  （这条在测试里验过：存了 `light` 而系统是深色，打开仍然是浅色）。
- 顺手补了 `color-scheme` 的坑：只靠 head 里的 `<meta name="color-scheme">` 会让原生控件
  （滚动条、input）跟**系统**配色走，深色系统 + 手动切白天时滚动条仍是深的。现在两边都写死。
  滚动条颜色也走变量（`--scroll-thumb`），用 `scrollbar-width: thin` + `scrollbar-color`，
  这里没写 `::-webkit-scrollbar` 那套，所以可以直接用。

**抽屉搜索**：

- 第二列顶部加 `<input type="search" id="drawerSearch">`，`input` 事件即时过滤（子串、忽略大小写）。
- 提示行会随状态变化：没搜时讲怎么拖；搜了以后变成「匹配 2 / 3 个标签」，让人知道筛掉了多少。
- 零命中时给独立空态「没有匹配「zzz」的标签」，而不是和「还没有标签」混用一句话。
- 切换「标签 ⇄ 分类」时自动清空搜索词（留着上一个关键词只会让人困惑），placeholder 跟着改。
- 打开抽屉时焦点直接落到搜索框。
- 搜索框里按 `Esc`：有词就先清词（`stopPropagation`，别让全局 Esc 把整列一起收了），没词才收列。
- `.drawer-list` 补了 `flex: 1; min-height: 0` —— 搜索框吃掉一块高度后，列表得自己吃掉剩余空间
  才滚得动；少了 `min-height: 0`，flex 子项默认的 `min-height: auto` 会把抽屉顶破。

**验证**：临时页面在 iframe 里跑端到端（跑完已删）——

- 筛「算法」得 2 条（哈希算法 / 算法基础）、「哈希」得 2 条、「zzz」得 0 条并显示空态、清空回 3 条
- 点按钮：`light → dark`，`localStorage['mgr.theme'] = dark`，title 变「切换到白天」；再点回 `light`
- 存 `light` + 系统深色 → 打开仍是 `light`（手动选择优先于系统）
- 切到分类：搜索值清空、placeholder 变「搜索分类」、条目变 1 条
- 白天/黑夜两版截图各一张，搜索框、图标、文字都正常

**为什么**：深色是跟着系统走的，工具在白天看着发白的时候没法自己调；抽屉里的标签一多
（现在只有 3 个，以后几十个）就得靠搜，靠肉眼在一列里找太慢。

**提交**：本次改动已提交
