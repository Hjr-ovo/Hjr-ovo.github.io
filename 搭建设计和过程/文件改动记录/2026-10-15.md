## 15:50 修复 · ICO 补 AND 掩码，修复桌面快捷方式显示默认白图标

**改了什么**：`图标生成/generate-icons.py` 的 `_dib_bytes` 补齐 AND 掩码行
（`biHeight = 2×高度` 是「彩色图 + 掩码图」的总高，只写一半数据 Windows 解析越界）；
新增 `check_ico_structure` 硬校验（目录项尺寸 0 → 256、biHeight 核对、数据块长度核对）；
`图标生成/make-shortcut.py` 重写为手写 MS-SHLLINK 结构（Header 76 字节含 Reserved3，
字符串块 GBK 编码）。重新生成桌面 `博客管理工具.lnk` 与全套图标。

**为什么**：用户截图反馈快捷方式是白色默认文档图标。根因是 Pillow 对畸形 ICO 宽容、
逐帧验收抓不到，而 Windows 严格——BMP 帧数据只有一半时直接解析失败、回退默认图标。

三个坑（当天连续踩到）：
- **沙箱假绿**：写 `C:\Users\20138\Desktop` 被沙箱拦截，但脚本同进程读回自检
  「通过」——读到的也是沙箱层。必须禁沙箱跑 + 独立进程复核文件是否真在桌面。
- **目录项尺寸字段**：1 字节，256 规范约定写 0，校验时要按 256 解释。
- **COM 全被安全策略拦**：WScript.Shell / Add-Type / pip pywin32 都建不了快捷方式，
  只能纯 struct 手写 lnk 二进制。

**验证**：独立进程确认 lnk 落在真实桌面；`check_ico_structure` 全档通过；
Explorer 图标缓存刷新后显示正确图标。

## 13:18 新增 · 博客与后台工具换上 logo 应用图标

**改了什么**：新增 `图标生成/` 目录（`generate-icons.py` 多档图标生成 +
`make-shortcut.py` 桌面快捷方式，改图后重跑这两个脚本即可，勿手改产物）。
源图 `图标生成/logo.png`（阿然手绘头像，暖白纸底）。产物：站点 favicon 全套
（`site/public/` 下 favicon.ico/png、apple-touch、icon-192/512）、工具 favicon
（`博客管理工具/public/`）、Windows 大图标 `博客管理工具/app.ico`、
桌面启动快捷方式 `博客管理工具.lnk`。删除旧 `site/public/favicon.svg`
（不删则支持 svg 的浏览器仍显示旧图案）。

**为什么**：用户原话「给我的博客本体和后台都做一个启动图标，就用这个图片」。

两个手工决策：
- **小尺寸（≤64px）居中裁 0.88**：头像在源图里不居中，直接缩到 16px 会偏。
  这个比例是手工试的，**换 logo 必须人工复核**。
- **ICO 自己拼容器**：Pillow 保存 ICO 会把多档位抹平（只剩一档），
  必须手写目录 + 逐档数据块。

## 13:18 新增 · 后台工具：分类/标签总览、点击筛选、改名合并

**改了什么**：新增 `博客管理工具/src/taxonomy.mjs`（`listTaxonomy` 统计 +
`renameTaxonomy` 改名/合并，支持 `dryRun` 只算不写），`server.mjs` 接入
`/api/taxonomy` 与 `/api/taxonomy/rename` 两个接口。前端列表页顶部新增
「分类」「标签」两个总览区：显示名称与篇数（草稿另计），**点一下筛选下方列表、
再点取消**；每个分类/标签旁带「在博客里看」小链接，直跳站点对应页面。
总览区提供「改名 / 合并」入口：弹窗里显示将影响多少篇文章、新旧 URL 对比，
确认后改 frontmatter 并**自动往 `redirects.json` 补跳转**（分类名进 URL，
不改旧地址会 404）。编辑文章时，分类候选从写死的 `CATEGORIES` 常量改为
「文章里实际用过的分类」（常量兜底），标签加候选提示。

**为什么**：分类/标签名是手打的，「计算机网络」和「计算机网络 」能差出一个空格，
站点侧就会裂出两个分类页。工具里能直接看到全站用了哪些名字、点一下就能筛出
在用它们的文章、改名时自动补重定向——把「手滑打错」的代价降到零。

**验证**：端到端测试（`.workbuddy/tmp/test-taxonomy.mjs`）覆盖统计 / dryRun 隔离 /
真改名（改 frontmatter + 写重定向）/ 合并去重 / 参数校验 / 构建产物（旧地址跳转页、
新地址真实页）/ 清理还原。
