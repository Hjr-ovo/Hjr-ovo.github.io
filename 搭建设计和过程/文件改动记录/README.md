## 这里的规矩

| 规则 | 说明 |
|---|---|
| **一天一个文件** | 文件名是**当天日期**，`YYYY-MM-DD.md` |
| **新建方式** | 复制同目录 `模板.md`，重命名为当天日期 |
| **排列顺序** | 文件内表格**倒序**，最新改动放最上面 |
| **一次操作 = 一行** | 哪怕一次动了 5 个文件，也合成一行 |
| **类型只用 5 个词** | 新增 / 修改 / 删除 / 重构 / 样式 |
| **提交号先标 `——`** | 提交完才知道号，写新条目时顺手回填上一条 |
| **纯记账提交不占行** | 回填提交号、改错别字这类不单独写一行，否则无限套娃 |

完整规则见同目录 [`模板.md`](模板.md)。

## 关于"自动生成索引"

Obsidian 有 Dataview 插件能自动列出文件夹内文件，但**本项目不用**，原因：

- Dataview 是 Obsidian 插件，靠打开笔记时扫描 vault 实时计算。本项目不在 Obsidian vault 内，
  也没有任何程序会去"运行"它
- 现在记录量很小（一个月个位数），手写索引比搭一套自动化更省事
- 手写还能写"备注"列，自动生成的只有干巴巴的链接

> 什么时候该重新考虑：如果记录多到**每次补索引都觉得烦**，再上自动化。
> 那时可选的方案是写个脚本扫描这个文件夹生成索引，仍是手写的替代品而非必需品。
