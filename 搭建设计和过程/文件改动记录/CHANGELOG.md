# 文件改动记录

> 一次操作 = 一行。**倒序排列，最新的在最上面。**
> 类型只用 5 个词：新增 / 修改 / 删除 / 重构 / 样式
>
> 「提交」列 = 这次改动所在的 git 提交号。提交号得提交完才知道，所以规则是
> **写新条目时顺手回填上一条**，最新那条暂时标 `——`。
> 想查某次改动具体动了哪些行：`git show <提交号>`。
>
> **纯记账性提交不单独占一行**（比如回填提交号、改错别字），否则会无限套娃。
