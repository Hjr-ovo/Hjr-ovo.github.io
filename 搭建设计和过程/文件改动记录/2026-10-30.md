## 23:05 新增 · 文章支持多语言代码切换，代码块加一键复制

**改了什么**：

- 新增 `site/src/utils/remark-code-tabs.mjs`：一个 remark 插件，把连续的 `+tab` 代码块
  包成 `<div class="code-tabs">` 容器 + 若干 `<div class="code-tab-panel" data-lang>` 面板。
- `site/astro.config.mjs`：`remarkPlugins` 从 `[remarkMath]` 改成 `[remarkMath, remarkCodeTabs]`。
- `site/src/pages/posts/[...slug].astro`：末尾加一段脚本，负责生成标签栏、切换面板，
  并给页面上所有代码块加「复制」按钮。
- `site/src/styles/global.css`：新增 `.code-tabs` / `.code-tabs-bar` / `.code-tabs-tab` /
  `.code-tab-panel` / `.code-wrap` / `.code-copy` 样式，全部走 CSS 变量。
- `搭建设计和过程/设计方案/架构设计.md`：新增「五之四、多语言代码切换」。

**写作约定**（作者侧完全不用学新语法）：

````text
```cpp+tab
…
```

```java+tab
…
```

```python+tab
…
```
````

连续的 `+tab` 块自动合成一组；同一组里语言重复出现就自动开新组。
语言名不设限，`rust+tab`、`go+tab` 都能用。

**为什么**：用户问「可不可以做切换语言，切换 C++/Java/Python」，选的是「每段代码独立
切换」（方案 A），并要求顺带做代码块一键复制。写哈希算法那篇时同一个例子要用三种语言
各写一遍，读者只能自己在三块代码里翻，体验差。

**关键实现约束（两个）**：

1. **不能写成 rehype 插件**。Astro 的 Shiki 高亮在用户 rehype 插件**之前**执行
   （`@astrojs/markdown-remark/dist/index.js` 里先 `use(rehypeShiki)` 再 `use(rehypePlugins)`），
   到 rehype 阶段原始代码块已经被替换成高亮结果，结构拿不到。改在 remark 阶段用
   `data.hName` / `data.hProperties` 包容器，内层 `<pre>` 保持标准结构，Shiki 照常高亮。
2. **必须把 `lang` 从 `cpp+tab` 改回 `cpp`**。否则 `+tab` 会被 Shiki 当成不存在的语言，
   警告后回退成纯文本。

**验证**：临时文章放 3 组共 7 个面板 → 3 个容器、7 个面板、4 个面板默认隐藏、
8 个复制按钮；`data-language` 全部正确、0 条 `[Shiki]` 警告；真实浏览器点第 2 个标签，
面板可见性 `[true,false,false] → [false,true,false]`、`aria-selected` 同步；
320–1440px 九档宽度 0 横向溢出；浅色/深色截图正常；`npm run build` 通过（exit=0）。
测试用临时文章与量宽页面已删除。
